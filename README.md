
# 💎 Number Guessing Game

A fun and interactive number guessing game built using HTML, CSS, and JavaScript.

## 🎮 Features

- Random secret number between 1 and 100
- Higher and lower hints after each guess
- Attempt counter
- Best score tracking during the current page session
- Input validation
- Win message when the correct number is guessed
- Play Again button
- Responsive and colorful interface

## 🕹️ How to Play

1. Enter a whole number between 1 and 100.
2. Click **Check My Guess**.
3. Follow the Too High or Too Low hints.
4. Find the secret number in as few attempts as possible.
5. Click **Play Again** to start a new game.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
